# MiniC Lab 课程设计报告

## 摘要

MiniC Lab 使用 Java 21 实现一门类 C 教学语言的编译器，将源码经词法、语法和静态语义分析转换为四元式，再进行局部优化和栈式字节码生成，最终在自研虚拟机中执行。Swing 桌面界面展示各阶段产物与源码对应位置。独立实验台实现正规式自动机、LL(1) 与 LR 系列算法，用于复习算法构造与分析过程。

## 1. 需求与边界

项目依据七章期末复习主题，既要求生成真实可执行目标，也要求能解释过程。源语言选用 int/bool/void、局部变量、函数、分支、循环和输入输出，保留足够多的类型、作用域、控制流和递归案例。完整 EBNF 和约束见 SPEC。

未实现完整 C、原生机器码、SSA、数组、浮点、指针和全局变量。理论范围中没有转化为交互算法的内容在考点对照表中明确标识。用户未提供评分模板或身份信息，本报告不编造院校、姓名、学号或外部验收结果。

## 2. 总体设计

程序分为 core、lab、ui 三层。CompilerService 提供统一编译入口，CompilationResult 保存 Token、AST、语法调用轨迹、语义结果、原始/优化四元式、字节码及诊断。core 和 lab 均不依赖 Swing，可直接自动测试。

主要数据结构：

| 结构 | 作用 |
|---|---|
| Token + Span | 词素、类别、UTF-16 起止偏移及一基行列 |
| Syntax 中的 record 节点 | 结构化 AST；Node.span 支撑源码跳转 |
| Scope 链 + Symbol | 词法作用域查找、唯一符号号与局部槽 |
| IdentityHashMap<Node,Attr> | 以节点身份保存类型、常量与绑定，避免相同结构节点混用属性 |
| Flow(reachable,assigned) | 描述正常流是否仍可达及确定赋值集合 |
| Quad / Instruction | 四元式和带源码位置的目标指令 |
| VM Frame | 函数、PC、局部槽数组和操作数栈 |
| 有穷状态集合 / 产生式 / LR Item | 自动机和文法实验的核心形式化对象 |

## 3. 编译前端

### 3.1 词法分析

Lexer 从左到右扫描字符，按标识符、数字、注释、双字符运算符和单字符分隔符分流。关键字由已识别标识符查询固定集合得到。采用最长匹配识别 ==、!=、<=、>=、&&、||。非法字符、错误数字、超范围整数与未闭合注释产生诊断。

### 3.2 语法分析

Parser 使用递归下降，每种语句结构对应分析函数。表达式按逻辑或、逻辑与、相等、大小比较、加减、乘除余、一元运算依次分层；同级二元运算左结合，递归处理一元运算和括号。if/else 与 while 强制使用块，避免悬空 else 造成讲解歧义。

语句出错后扫描至分号或右大括号；顶层恢复至下一个函数定义起点。错误程序可以留下部分 AST，但不能进入目标代码生成。限制输入和语法树深度，避免构造超深树导致宿主栈溢出。

### 3.3 静态语义与属性

先注册所有函数签名，允许前向调用和相互递归；随后分别分析函数体。每个函数参数占用最前面的局部槽，后续局部变量按声明分配。每个 Symbol 有全局唯一编号，相同源码名字在不同块中可以拥有不同编号。

类型规则无隐式 int/bool 转换。运算、赋值、参数和返回值分别检查类型。read()/write() 作为有固定签名的内置函数，局部声明若遮蔽函数名，后续调用会报错。

确定赋值以集合追踪：声明初始化和赋值加入变量号；读取必须在集合中；if 合流取能正常到达后续语句的分支交集，已 return 的路径不参与交集；循环保守视为可能执行零次。break/continue 以循环深度校验；非 void 函数若仍可正常落到末尾则报告缺少返回。

节点 type、constant、binding 是综合结果，scope 是继承环境。界面还显示节点对应四元式区间。常量属性只用于记录可安全计算的信息，不绕过类型检查或删除具有副作用的表达式。

## 4. 中间代码与后端

四元式使用 vN 表示已绑定变量、tN 表示临时量、LN 表示标签。表达式结果进入临时量；分支和循环转换成条件跳转和无条件跳转；break/continue 使用目标标签栈，始终绑定最近一层循环。

短路逻辑先计算左侧，再通过跳转决定是否计算右侧。函数调用先从左到右计算全部实参，再生成 param/call，避免嵌套调用时参数交错。函数返回值可存入临时量，即使作为独立调用语句也不会残留在操作数栈上。

优化在基本块内部维护临时量替换信息，完成常量折叠及临时量复制传播。标签、跳转、返回、调用、输入输出是信息屏障。除零/余零运算保留至 VM，以保持异常发生顺序与源码位置；不采用可能消除副作用的 x*0 等激进重写。

Bytecode 将四元式操作数转换为 PUSH/LOAD，将结果转换为 STORE，二元计算由栈顶两个值完成。标签在第二遍回填为函数内部 PC。每条指令携带原始 Span。运行使用所选优化版本；两份 IR 均保留供比较。

## 5. 栈式虚拟机

VM 只处理字节码，不执行 AST。CALL 按参数数量取值并创建独立帧；RET 销毁帧，将返回值压入调用者栈，main 返回后进入 HALTED。独立槽数组保证递归调用不会覆盖前一次调用的局部变量。

状态包括 READY、RUNNING、PAUSED、HALTED、STOPPED、ERROR。单步执行一条目标指令，运行循环在每条指令边界检查暂停、停止和累计资源预算。错误包含源码位置；输入不足、除零和资源超限可区分。

int 行为采用 Java 32 位有符号整数回绕和向零截断除法。用户输入独立于系统标准输入，GUI 的整数列表和 CLI 的 --input 均预先提供给 VM，便于重放实验。

## 6. 复习实验算法

### 6.1 自动机

Thompson 为字面符号、空串和空语言创建片段，对连接、并和闭包添加 ε 边。子集法以 ε-closure({start}) 为初态，逐个字母计算 closure(move(I,a))；显式保留空集陷阱状态，使 DFA 转换完整。最小化从终态/非终态分组出发，反复按各符号的目标分组划分状态，直到分割不变。

### 6.2 LL(1) 与文法变换

FIRST 与 FOLLOW 通过单调不动点迭代求解。FIRST 能产生 ε 的非终结符构成 Nullable；SELECT 根据 FIRST(右部) 及可空时的 FOLLOW(左部) 得到。预测表单元保留所有候选式，有交集则报告冲突而非默认选第一项。

直接左递归消除按 A→Aα|β 转为 A→βA'、A'→αA'|ε；提取公因子反复寻找最长公共前缀。左角图考虑 Nullable 前缀并检测间接左递归，间接变换留给学习者手工处理。

### 6.3 LR 系列

将文法拓广，使用 closure 与 goto 构造项目集 DFA。LR(0) 在全部终结符及 # 上填写完成项目规约；SLR(1) 只在产生式左部 FOLLOW 上规约；规范 LR(1) 在 closure 中传播 FIRST(βa) 展望符，并仅在项目展望符上规约。

移进、规约和接受动作去重后仍全部保留；一个单元出现多个动作即报告冲突，分析器不自行采用优先级或默认规约。回放记录每步动作前的状态栈、符号栈与剩余输入。

## 7. 桌面与文件交互

Swing 在 EDT 更新组件，编译、连续执行和算法构造在 SwingWorker 工作线程执行。编译结果关联源码修订号；源码或优化选项变化会禁用运行和导出。后台结果只有与当前修订一致时才接入界面，防止旧结果覆盖新输入。

文件使用 UTF-8，打开前检查大小，覆盖导出需确认。算法构造循环检查取消信号并限制状态规模。图使用 Java2D，无外部绘图库；支持缩放、平移与初态/终态显示，但不承诺复杂图无边交叉。

## 8. 测试与复现

`mvn -B verify` 运行自动测试并打包。测试以可独立核对的结果为准，包括阶乘输出 120、累加输出 5050、课件 LR(0) 文法 10 状态、表达式 SLR(1) 12 状态/规范 LR(1) 22 状态，以及 (a|b)*abb 的最小 DFA 4 状态。优化前后对比输出和可观察错误。

实际执行次数、桌面检查结果和未验证项以同目录《验证报告》为准；本报告的设计描述不替代运行证据。

## 9. 局限与可扩展点

当前确定赋值与返回检查保守，不利用常量条件证明控制流；大整数会按 int 回绕。自动机/文法实验有明确规模上限。字节码可导出为文本，但没有外部文本字节码加载器。可扩展方向包括数组、浮点类型、更丰富数据流优化、SSA 和原生后端，应分别新增语言规则、目标指令及测试，不能仅靠界面增加选项。
