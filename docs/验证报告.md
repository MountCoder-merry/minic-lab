## 构建与复现

使用 Build-Delivery.ps1 生成交付目录和 ZIP。脚本重新执行 Maven verify，再复制源码、文档、示例和启动脚本。运行包只需要 Java 21，不依赖 Maven。

已将 ZIP 解压到独立的 target/package-check 目录，在该目录使用包内 JAR 执行阶乘（输入 5 输出 120）和最大公约数（48 18 输出 6），均返回成功。包内 JAR 与构建 JAR 的 SHA-256 一致，检查无 src/src 或 docs/docs 嵌套重复目录。
