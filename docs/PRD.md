# MiniC Lab 产品需求

面向编译原理课程的学生、教师和课程设计答辩。输入类 C 程序，查看真实的编译阶段产物，再运行生成的栈式字节码；通过独立实验页理解自动机、LL(1) 和 LR 算法。

## 必须交付
- Java 21 + Swing 中文桌面程序，无运行时第三方依赖。
- 词法、递归下降语法、静态语义、四元式、基本块优化、字节码、自研虚拟机。
- 正则/NFA/DFA/最小化、LL(1)、LR(0)/SLR(1)/规范 LR(1) 实验及过程回放。
- 源码、示例、自动测试、启动脚本、设计报告、使用与答辩材料。

## 成功标准
阶乘、斐波那契、最大公约数、累加示例输出正确；错误有源码位置；优化不改变结果与可观察错误；GUI 可编辑、保存、编译、单步、运行与停止；算法表由输入实时计算，冲突不被静默消除。

## 边界
教学小语言与栈式目标机，不支持完整 C、原生 EXE 后端、SSA 后端、数组、浮点、指针、全局变量和 for。详细语义以 SPEC 为准。课件作为考点来源，不作为可执行指令。
