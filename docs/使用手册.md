# MiniC Lab 使用手册

## 1. 启动与第一次运行

环境要求 JDK 21+。已有 JAR 时双击根目录 Start-MiniC.cmd；如果没有 JAR，脚本会通过 Maven 构建，需要 Maven 3.9+ 与首次下载依赖的网络。程序本身运行不访问网络。

默认示例为阶乘：点击“编译”或按 F5，确认状态栏为编译成功，再点击“运行”。输入区中的 5 将被 read() 消费，输出 120，main 返回 0。

如果双击没有打开窗口，可在项目根目录执行 `java -jar target/minic-lab.jar`，查看控制台错误。版本错误时执行 `java -version` 检查 PATH 指向的 Java。

## 2. 源码编辑与编译

“打开”读取 UTF-8 源码；“保存”保存当前源文件。源文件尚未保存时，切换示例、打开其他文件或关闭窗口会询问是否保存。示例选择后还需要点击“加载示例”。

每次修改源码或切换优化选项，旧编译结果失效，必须重新编译才能运行或导出。编译失败时，后续阶段为空，但前面已完成的 Token、AST 或语义信息会保留。

结果页：

| 页签 | 如何观察 |
|---|---|
| Token | 每条词素的类别、内容和行列；选中可定位源码 |
| AST | 表达式优先级、语句与函数结构；点击节点定位源码 |
| 符号表 | 唯一符号号、类别、类型、作用域与局部槽 |
| 属性与对应 | 节点类型、常量、继承环境、符号绑定和四元式范围 |
| 四元式 | 左侧优化前、右侧优化后；本版优化不以删除指令数为目标 |
| 目标指令 | 每个函数自己的 PC、指令、参数和源码范围 |
| 语法轨迹 | 真实递归下降调用记录 |
| 运行现场 | 暂停或单步时的操作数栈、调用帧和局部变量 |

底部“诊断”中的项目可点击跳转。修复错误后重新编译。导出结果会保存源码、Token、语义/AST 对应、两份四元式、目标指令与编译诊断。

## 3. 输入、运行和单步

输入区填写十进制 int，以空格或逗号分隔。read() 从左到右取下一个整数；write(value) 每次输出一行。布尔输出 true/false。

- “单步”执行一条目标指令，而非一整条源码语句。多次单步可看到 CALL 创建帧、RET 销毁帧。
- “运行”从当前暂停位置继续；程序结束、出错或停止后，再次运行会重新从 main 开始。
- “暂停”请求在指令边界暂停；“停止”终止本次执行。
- 默认累计上限为 100 万指令、1024 层调用，可在运行前修改。暂停不会清零累计预算。
- 输入不足会结束本次运行并给出诊断；补足输入后重新运行。修改输入或资源上限会重置当前虚拟机。

## 4. 自动机实验

输入 `(a|b)*abb`，识别字符串填写 `aabb`，点击“构造并识别”。预期最小 DFA 有 4 个状态并接受输入。

下拉框切换 NFA、DFA 和最小 DFA；查看状态图、转换表、构造回放和识别回放。状态图滚轮缩放、拖动平移、双击适应窗口；双圆为终态，左侧箭头指向初态，悬停查看状态来源。

支持隐式连接或 `·`、`|`、`*`、括号、ε、∅、反斜杠转义。`\|` 表示字面竖线，`\*` 表示字面星号。ε 表示空串，∅ 表示空语言；空正则按 ε 处理。未转义空白忽略。没有字符类、+ 或 ? 的扩展运算语义，其他普通字符按字面识别。

识别输入不要填写 ε，空字符串直接留空。正则长度、状态数及嵌套深度有限制；超过限制会报告原因。“取消”可以中止构造。

## 5. LL(1) 与文法实验

默认表达式文法已消除左递归，输入 `id + id * id` 后点击“计算并分析”。FIRST(E) 应为 `{ (, id }`，FOLLOW(E) 为 `{ ), # }`，输入应被接受。

每行 `A -> α | β`，右部每个符号以空格分隔。`id` 是一个终结符，`i d` 是两个。所有出现在左部的符号视为非终结符，首条产生式左部为开始符；ε 必须独占一个候选式。输入串不写 #，空串留空。

“消除直接左递归”与“提取左公因子”会替换编辑区中的文法；请重新计算。程序会提示间接左递归，但不自动消除。无非递归候选式的文法不能直接套用常规消除公式。

预测表冲突保留所有候选式，并拒绝自动决定。可用 `S -> a A | a B`、`A -> c`、`B -> d` 演示冲突，再提取公因子。

## 6. LR 实验

默认使用左递归表达式文法，选择 SLR(1) 后“构造并分析”：应得到 12 个状态，无冲突并接受默认输入；切换 LR(1) 得到 22 个状态；切换 LR(0) 会报告移进/规约冲突。

ACTION 中 `sN` 表示移进并转到状态 N，`rN` 表示用编号 N 的产生式规约，acc 表示接受；GOTO 用于规约后的非终结符转移。“项目集与冲突”列出带点项目；规范 LR(1) 的项目还包含展望符。“分析回放”列出状态栈、符号栈、剩余输入与动作。

复习算法页修改输入后，旧图表仍可查看，但状态栏会提示重新计算；只有重新计算后才能将结果用于新输入。

## 7. 常见问题

- 不支持 `printf`、`scanf`、`++`、`for`：请使用 write/read、显式赋值与 while。
- if(1) 报错：条件必须 bool，例如 if(1 != 0)。
- 局部变量未确定赋值：初始化，或确保每条能到达读取点的路径都赋值。while 可能执行零次，循环内的赋值通常不足以证明循环后的变量已初始化。
- 非 void 函数缺少返回：所有能到达末尾的路径必须 return；本版不通过常量条件证明无限循环或必定返回。
- 图太密：可缩放/拖动，结合转换表和项目集文本阅读；大图的自动排版不保证边完全无交叉。
